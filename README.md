# site-estetica

Site FICTÍCIO de página única, criado para uma clínica de procedimentos estéticos no bairro Buritis, em Belo Horizone ("Espaço Beleza Buritis").

## Elementos

- Nav (Menu) com:
  - Nome da Loja "Espaço Beleza Buritis", com um link para o topo da página
  - Links de "Nossa História", "Procedimentos", "Onde Estamos" e "Avaliações", levando para essas quatro seções da página
- Header (Hero) com:
  - H1 "Clínica Estética no Buritis, Belo Horizonte"
  - Imagem da logo com o fundo rosé
  - Botão com o link para whatsapp da clínica
- Section "Sobre Nós" ("Nossa História" no Nav):
  - Parágrafo com a descrição da história da clínica
  - 2 imagens do interior da clínica
  - 1 vídeo (hospedado no Vimeo, por "iframe") com o interior da clínica
- Section "Procedimentos" ("Procedimentos" no Nav):
  - 8 cards de procedimento, cada um contendo uma imagem, o nome do procedimento, descrição em uma frase sohre o que é o procedimento, e seu preço
